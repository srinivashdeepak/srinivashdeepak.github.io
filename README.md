# Deepak M | Portfolio

Personal portfolio website of **Deepak M**, a Python full-stack developer and Electronics and Communication Engineering graduate (2026) based in Bengaluru.

**Live site:** https://srinivashdeepak.github.io

## About

This site shows my projects, internship experience, skills, education, and contact details. It is a single static page: one `index.html` file with the HTML, CSS, and JavaScript together. There is no build step and nothing to install.

## Features

- Responsive layout for phones, tablets, and desktops
- Light and dark themes that follow the system setting, with a manual toggle
- Accessible markup: semantic headings, keyboard focus styles, and reduced-motion support
- "Copy email address" button
- Fast loading with no frameworks or libraries
